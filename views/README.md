# views/ – Die Ansichten

Jede Ansicht hat einen eigenen Ordner. Darin liegt **alles, was nur diese Ansicht betrifft** – JavaScript und CSS zusammen.

| Ordner | Wer sieht das? |
|---|---|
| `login/` | Alle – Code eingeben, danach geht's zur richtigen Ansicht |
| `staff/` | Bergbahn-Mitarbeiter und Skischulen |
| `guest/` | Gäste (optional – der Chip funktioniert auch ohne App) |

**Gehört hier NICHT rein:** Dinge, die mehrere Ansichten brauchen (z. B. die Karte) → `js/` bzw. `css/`.
