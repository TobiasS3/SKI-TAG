# views/staff/ – Mitarbeiter-Ansicht

Für Bergbahn-Mitarbeiter und Skischulen. SOS-Alarme erscheinen als **roter Punkt** auf der Karte, der Alarm geht an den **nächsten Mitarbeiter**.

| Datei | Inhalt |
|---|---|
| `staff-view.js` | Hauptseite: baut Karte und Listen zusammen |
| `alarm-list.js` | Liste aller aktiven SOS-Alarme |
| `alarm-detail.js` | Ein einzelner Alarm: wer, wo, seit wann, wer ist zuständig |
| `chip-list.js` | Übersicht aller aktiven Chips |
| `staff.css` | Aussehen nur dieser Ansicht |
