# js/components/ – Wiederverwendbare Bausteine

Kleine UI-Teile, die in mehreren Ansichten vorkommen.

| Datei | Inhalt |
|---|---|
| `modal.js` | Popup-Fenster (z. B. „SOS bestätigen?“) |
| `toast.js` | Kurzer Hinweis unten am Bildschirm |
| `nav.js` | Navigation |
| `panel.js` | Ausklappbarer Bereich / Infobox |
| `user-menu.js` | Menü oben rechts (Bergbahn, Skischule) |
| `icons.js` | Symbole als SVG |

Das passende Aussehen liegt in `css/components/` mit gleichem Namen.
