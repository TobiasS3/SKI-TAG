# js/core/ – Das Gerüst der App

| Datei | Inhalt |
|---|---|
| `router.js` | Welche Ansicht wird gezeigt (`#/staff`, `#/guest` …) |
| `auth.js` | Code prüfen → Rolle (Gast / Mitarbeiter / Skischule) |
| `session.js` | Zugang läuft am Tagesende aus |
| `state.js` | Aktueller Zustand der App (wer ist eingeloggt, welche Daten geladen) |
| `events.js` | Teile der App benachrichtigen sich gegenseitig (z. B. „neuer SOS“) |
| `storage.js` | Daten im Browser speichern |
