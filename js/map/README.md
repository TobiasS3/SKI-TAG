# js/map/ – Die Karte (Leaflet + OpenStreetMap)

| Datei | Inhalt |
|---|---|
| `map.js` | Karte erstellen |
| `markers.js` | Punkte auf der Karte (du, Gruppe, Mitarbeiter, Kinder im Skikurs, roter SOS-Punkt) |
| `layers.js` | Ebenen, z. B. Pisten ein-/ausblenden |
| `geo.js` | Rechnen mit Koordinaten – z. B. nächster Mitarbeiter zum SOS |
