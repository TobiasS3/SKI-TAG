# assets/ – Bilder, Icons, Töne

| Ordner | Inhalt | Format |
|---|---|---|
| `images/` | Logos, Hintergrundbilder | SVG oder PNG/JPG/WebP |
| `icons/` | App-Icon (Homescreen) + kleine Symbole | PNG 192×192 + 512×512, sonst SVG |
| `sounds/` | Alarmtöne (SOS) | MP3 |

**Dateinamen:** klein, ohne Leerzeichen und Umlaute – z. B. `logo-kitzski.svg`, `marker-sos.svg`.
