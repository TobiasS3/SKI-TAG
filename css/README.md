# css/ – Gemeinsames Aussehen

`main.css` bindet alles ein – auch die CSS-Dateien aus `views/`.

| Ordner | Inhalt |
|---|---|
| `base/` | Grundlagen: **Farben** (`variables.css`), Reset, Schrift, Grundlayout |
| `components/` | Aussehen der Bausteine – gleiche Namen wie in `js/components/` |

**Farbe ändern?** → nur in `base/variables.css`.
**Aussehen nur einer Ansicht?** → `views/<ansicht>/<ansicht>.css`.
